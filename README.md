# aruco-vision-api

ArUco検出、カメラ校正、ロボットベース座標への変換を提供する独立コンポーネントです。

同僚版の `aruco_pickplace` は `../../reference/aruco_pickplace` に参照用として保持し、
このリポジトリでは画像処理と座標提供APIをロボット移動処理から分離します。

## 方針

- PC側はPython 3.11を使用する
- Raspberry PiのカメラサーバーとPC側画像処理を分離する
- カメラ行列、歪み係数、hand-eye変換を校正データとして管理する
- マーカー未検出や校正不整合時には座標を返さない
- ロボットを直接移動する処理はこのリポジトリに入れない

## 現在の状態

初期スキャフォールドです。検出・座標変換APIは参照版の検証後に実装します。
